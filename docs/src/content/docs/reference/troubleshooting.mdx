## Circle / Arc

**`no agent session is active`** — the address is not a Circle agent wallet, or you are
not logged in for that network. Check `php artisan lepton:login --status` and
`circle wallet list --type agent --chain ARC-TESTNET`. Also run `lepton:doctor`: it
prints the env, database and Circle treasury addresses side by side — a mismatch is the
bug.

**Transfers fail on testnet while the wallet looks funded** — you are authenticated for
mainnet only. Mainnet and testnet are independent sessions.

**`method 'trace_block' not allowed by the proxy`** — the Arc RPC proxy is allowlisted
by design; that method is not exposed. Not a setup bug.

**`Faucet drip failed (429)`** — you hit the per-user faucet cap. The faucet mints
exactly 20 USDC per call and ignores `--amount`; after ~5 drips it rate-limits. A
realistic funded balance is ~100–200 USDC. Do not retry in a loop; wait, or use a second
agent wallet.

**Auto-pays fail with “asset amount owned by the wallet is insufficient”** — the local
ledger claims a balance the chain does not hold. Use **Sync from chain** and check
`lepton:doctor` for drift. Never seed a demo with a balance the chain cannot back.

**A balance reads as 0** — you are probably pointed at an `arc-canteen` local wallet
instead of your Circle agent wallet, or you are querying a chain you are not
authenticated for. On Arc, USDC is the gas token, so “no gas” also reads as zero.

**`lepton:status` fails with “Wallet not found … on ARC”** — `circle wallet limit` is
mainnet-only; this is expected for a testnet wallet. Check the session with
`isAuthenticatedFor('ARC-TESTNET')` (or `lepton:login --status`) instead.

**Every Lepton call fails with “No version is set for shim”** — `which circle` resolves
to a broken `mise` shim. Set `LEPTON_CIRCLE_BIN` to the absolute path of the npm global
binary.

**Agent-wallet transfer ends `unknown` and no transaction appears** — expected with the
installed CLI: without `--quiet`, `circle wallet transfer` returns a fee preview only and
does not broadcast; with `--quiet` it returns a Circle transaction **id** (UUID), not a
hash. The working path is quiet submit → poll `circle transaction list` until
COMPLETE/FAILED → take the hash → `ArcSettlementVerifier`. Do not record the Circle id as
a hash, and do not retry an `unknown` by resending — the payment may already have been
accepted.

## Environment & tooling

**`migrate:fresh --seed` deleted my AI providers and keys** — `ai_providers` is an
application table. Use `migrate:refresh` for demos, or re-enter the key; the encryption
protects a dump, not a deleted row.

**Feature scaffolding disappeared** — something ran `php artisan install:features`, which
consumes the chisel system (markers stripped, `chisel.php`, `chisel-paths.php` and
`app/Console/Commands/InstallFeaturesCommand.php` deleted). Composer's `post-update-cmd`
does **not** run it, so check your own scripts/CI; recover with
`git checkout -- chisel.php chisel-paths.php app/Console/Commands/InstallFeaturesCommand.php`.

**Tailwind v4 build error about `@layer components`** — a stray `postcss.config.js` in a
parent directory is being picked up. Keep the project-local empty `postcss.config.js`
(`{ plugins: {} }`) in place.

**Vite manifest error (“Unable to locate file in the Vite manifest”)** — run
`npm run build` (or `npm run dev`) so assets exist.

## Application behaviour

**`app:demo` is not repeatable** — each run spends 85 USDC. Re-fund, or use
`LEPTON_DRIVER=fake`.

**Background finance does nothing** — the planning runtime is enabled in
`config/eduflow.php`, so it only lacks plumbing: configure a durable
`EDUFLOW_FINANCE_QUEUE_CONNECTION` (never `sync`), keep a supervised queue worker on the
`finance-planning` queue and invoke the Laravel scheduler every minute. Most scheduler
tasks submit no money — **except** `eduflow:autonomous-pipeline-bridge`, which defaults
on and can submit and reconcile a payment within its 50 USDC ceiling. Disable it with
`EDUFLOW_AUTONOMOUS_PIPELINE_ENABLED=false` if that is not what you want.

**A payment screen is stuck / a quote cannot be re-quoted** — a bill with an unresolved
consent (consented, unsettled, unallocated, non-rehearsal) refuses a *new* request key;
replaying the *same* key returns the stored quote.

**My legacy `admin@admin.com` / `user@user.com` accounts still exist** — older seeders
created them; `RolesAndPermissionsSeeder` now creates no users in any environment. As an
operator: review those accounts, rotate exposed passwords, revoke sessions and
unnecessary access, and preserve required audit evidence. Do not regenerate `APP_KEY`,
reset the database, or delete financial records as cleanup.

**Student wallet generation says slots are exhausted** — `circle wallet create` is capped
at 5 agent wallets per blockchain with no delete verb (1 is used by the treasury, so 4
remain on ARC-TESTNET). Read the remaining count with `student:generate-wallet --list`
before minting; each generation permanently spends a slot.

**The student wallet screen shows a stale balance** — wallet balances are cached for
`EDUFLOW_WALLET_BALANCE_CACHE_SECONDS` (30s); the refresh action bypasses the cache.

## When a check is uncertain

Never resolve an unknown outcome by writing `FAILED`: a missing RPC result cannot prove
fabrication (propagation delay, reorganisation and a hash from another network all look
the same). Keep it unresolved, reconcile without blind resubmission, and escalate to a
human. `vendor/bin/pest --agent='…'` is the fastest way to prove a route, page or
relationship behaves as expected.
