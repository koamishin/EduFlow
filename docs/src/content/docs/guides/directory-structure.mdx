## Reading order for a new contributor

1. The relevant action, service, interface, and tests — verify actual behavior first.
2. `README.md` and `PLAN.md` — product context and intended safety gates, not proof that every described behavior is current.
3. `.ai/rules/index.md` — area rules (they encode non-obvious traps; read the rule file
   matching the path you are about to touch).
4. `docs/` — this handbook: [How OpenSinop works](../../guides/workflows/) and
   [Money and evidence](../../guides/core-concepts/).
