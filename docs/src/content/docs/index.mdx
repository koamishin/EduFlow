OpenSinop is a self-hosted, open-source platform (MIT) that lets a school review the
student fees it has already collected, plan their permitted use inside a department's
approved budget, and — only after deterministic policy checks and human authorisation —
connect an approved bill to a USDC payment on the [Arc](https://docs.arc.io) network
through a Circle **Agent Wallet**.

The money decisions live in plain PHP, never in a language model. The model may explain
a decision; it never makes one, never holds a signing key, and never authorises a
transfer.

## Project status

OpenSinop is under active development. Self-hosting does **not** certify financial
readiness. Use simulated data (`LEPTON_DRIVER=fake`) or an explicitly authorised Arc
**testnet** pilot. Review the [Safety & Readiness](institution/safety-readiness/) page
before enabling any payment path.
